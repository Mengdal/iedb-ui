# 企业功能

IEDB Enterprise 提供生产级的高可用、安全性和数据管理能力，适用于关键业务场景。

### 激活许可证

将许可证密钥添加到配置文件:

```toml
# iedb.toml
[license]
key = "IEDB-XXXX-XXXX-XXXX-XXXX"
```

或通过环境变量:

```bash
export IEDB_LICENSE_KEY="IEDB-XXXX-XXXX-XXXX-XXXX"
```

### 验证许可证

启动 IEDB 后,检查许可证状态:

```bash
curl http://localhost:8000/api/v1/license/status \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

响应示例:

```json
{
  "success": true,
  "data": {
    "valid": true,
    "type": "enterprise",
    "expires_at": "2027-12-31T23:59:59Z",
    "features": [
      "cluster",
      "rbac",
      "audit_log",
      "query_governance",
      "tiered_storage",
      "backup_restore"
    ]
  }
}
```

## 从 OSS 升级

从开源版升级到企业版无需数据迁移:

1. **添加许可证密钥** — 在配置文件或环境变量中设置
2. **启用所需功能** — 根据需要配置企业功能
3. **重启服务** — 重启 IEDB 使配置生效

所有现有数据和配置保持不变,企业功能会自动启用。

## 配置示例

完整的企业部署配置，组合了多个企业功能：

```toml
# iedb.toml — 企业部署示例

# ============================================================
# 许可证 — 激活企业功能
# ============================================================
[license]
key = "IEDB-XXXX-XXXX-XXXX-XXXX"

# ============================================================
# 服务器 — 监听端口
# ============================================================
[server]
port = 8000

# ============================================================
# 存储后端 — S3 / MinIO / Azure / 本地
# ============================================================
[storage]
backend = "s3"
s3_bucket = "iedb-production"
s3_region = "cn-hangzhou"

# ============================================================
# 身份认证 — Token 鉴权
# ============================================================
[auth]
enabled = true

# ============================================================
# 集群 — 多节点高可用部署
# 角色: writer / reader / compactor
# ============================================================
[cluster]
enabled = true
node_id = "writer-01"
role = "writer"
cluster_name = "production"
seeds = ["10.0.1.10:9100", "10.0.1.11:9100"]
raft_bootstrap = true
coordinator_addr = ":9100"
raft_bind_addr = ":9200"
shared_secret = "your-secret-key"

# ============================================================
# 分层存储 — 热/冷数据自动迁移
# 降低 60-80% 存储成本
# ============================================================
[tiering]
enabled = true
hot_max_age_days = 30      # 30天后迁移至冷存储

[tiering.cold]
enabled = true
backend = "s3"
s3_bucket = "iedb-archive"
s3_region = "cn-hangzhou"

# ============================================================
# 压缩 — 合并小 Parquet 文件提升查询性能
# ============================================================
[compaction]
enabled = true
hourly_enabled = true

# ============================================================
# 保留策略 — 自动清理过期数据
# ============================================================
[retention]
enabled = true

# ============================================================
# 连续查询 — 定时自动执行聚合/降采样
# ============================================================
[continuous_query]
enabled = true

# ============================================================
# 审计日志 — 操作合规追踪
# ============================================================
[audit]
enabled = true
retention_days = 90        # 审计日志保留 90 天

# ============================================================
# 查询治理 — 速率限制和配额管理
# ============================================================
[governance]
enabled = true
rate_limit_per_min = 60          # 每分钟请求上限
max_queries_per_hour = 500       # 每小时查询上限

# ============================================================
# 查询管理 — 实时监控和取消活跃查询
# ============================================================
[query_management]
enabled = true
```
